# Velmira - E-Commerce Website

Velmira is a full-stack e-commerce web application designed to provide a smooth, modern, and user-friendly online shopping experience.

## 🚀 Features

- User Registration and Login
- Product Listing
- Product Categories
- Product Search
- Product Filtering
  - Category
  - Price
  - Rating
- Product Sorting
  - Price: Low to High
  - Price: High to Low
  - Rating
- Product Details Page
- Add to Cart
- Update Cart Quantity
- Remove Products from Cart
- Wishlist
- Customer-specific Cart and Wishlist
- Checkout Page
- Order Management
- Responsive Design
- MongoDB Database
- REST API
